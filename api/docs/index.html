Overview

RESTful API for Bahria University Past Papers Portal

Base URL: http://localhost/papers/api
Authentication: Most endpoints require a JWT token. Include it in the Authorization header as a Bearer token.

Success Response

{
  "success": true,
  "data": { ... },
  "meta": {
    "page": 1,
    "per_page": 20,
    "total": 100,
    "total_pages": 5
  }
}

Error Response

{
  "success": false,
  "error": {
    "code": "AUTH_REQUIRED",
    "message": "Authentication required"
  }
}

Authentication

Manage user authentication and sessions

POST /auth/login

Authenticate user with enrollment number or email

Request Body
Field Type Description
login* string Enrollment number or email address
password* string User password

Response

{
  "success": true,
  "data": {
    "user": {
      "id": 1,
      "enrollment_number": "01-134211-001",
      "email": "user@bahria.edu.pk",
      "full_name": "John Doe"
    },
    "token": "eyJhbGci...",
    "refresh_token": "abc123...",
    "expires_at": "2026-01-26T19:00:00Z"
  }
}
POST /auth/register

Register a new user account (Bahria email required)

Request Body
Field Type Description
enrollment_number* string Format: XX-XXXXXX-XXX
email* string Must be @bahria.edu.pk
full_name* string User's full name
campus* string Campus identifier
department* string Department code
POST /auth/refresh

Refresh JWT token using refresh token

GET /auth/me 🔒 Auth Required

Get current authenticated user information

POST /auth/firebase-login 🔥 Firebase

Authenticate using Firebase ID Token (for Collexa Flutter app integration). Automatically creates user if not exists.

Security: All user data is extracted from the verified Firebase token. No user input is trusted.
Request Body
Field Type Description
id_token* string Firebase ID Token from getIdToken()

How to get the ID Token (Flutter)

// Get Firebase ID token
String? idToken = await FirebaseAuth.instance.currentUser?.getIdToken();

// Send to Past Papers API
final response = await http.post(
  Uri.parse('http://localhost/papers/api/auth/firebase-login'),
  headers: {'Content-Type': 'application/json'},
  body: jsonEncode({'id_token': idToken}),
);

Response

  "success": true,
  "data": {
    "user": {
      "id": 516,
      "enrollment_number": "01-134211-001",
      "email": "user@student.bahria.edu.pk",
      "full_name": "John Doe",
      "campus": "Islamabad E-8",
      "department": "CS"
    },
    "token": "eyJhbGci...",
    "refresh_token": "abc123...",
    "expires_at": "2026-01-26T23:41:29+05:00",
    "is_new_user": false
  }
}
Note: Use the returned token for all subsequent API calls in the Authorization: Bearer {token} header.

Papers

Browse, search, and manage past papers

GET /papers

Retrieve a paginated list of papers with optional filters

Query Parameters
Parameter Type Description
campus string Filter by campus
department string Filter by department
semester integer Filter by semester (1-10)
course string Search by course code or title
teacher string Search by teacher name
exam_type string Mid, Final, Quiz, etc.
search string General search term
sort string Sort by: newest, popular, downloads
page integer Page number (default: 1)
per_page integer Items per page (max: 100)
GET /papers/{id}

Get detailed information for a specific paper

POST /papers 🔒 Auth Required

Upload a new past paper (multipart/form-data)

GET /papers/{id}/download

Download the paper file

GET /papers/trending

Get the most viewed papers

GET /papers/recent

Get recently uploaded papers

Favorites

Manage user's favorite papers (Backpack)

GET /favorites 🔒 Auth Required

Retrieve all papers saved to favorites

POST /favorites/{paper_id} 🔒 Auth Required

Add a paper to favorites

DELETE /favorites/{paper_id} 🔒 Auth Required

Remove a paper from favorites

Community Requests

Browse and create paper requests from the community

GET /requests

List community paper requests

Query Parameters
Parameter Type Description
status string Open, Fulfilled, Closed, All
campus string Filter by campus
search string Search by course code
sort string Sort by: votes, newest
POST /requests 🔒 Auth Required

Create a new paper request

POST /requests/{id}/vote 🔒 Auth Required

Toggle vote on a request

POST /requests/{id}/comments 🔒 Auth Required

Add a comment to a request
